Methods, interpretation & limitations

Based on the supplied run information and exported model outputs.

Input predictors

Monthly rainfall, temperature, soil moisture and NDVI, seasonal calendar terms, time index and lagged predictors.

Model configuration

RandomForestRegressor, chronological 80/20 train-test split, with a seasonal-climatology comparison. The supplied run metadata identifies this as a research prototype.

Validation metrics

MAE, RMSE and R² are reported for rainfall and temperature. Performance should be interpreted relative to the seasonal baseline and the limited test sample.

Interpretation of supplied evaluation results

    Important limitations

    • These outputs are research model results, not official forecasts, nowcasts or early-warning products.
    • Rainfall performance should be assessed carefully: the supplied Random Forest has a slightly higher MAE and slightly lower RMSE than seasonal climatology.
    • Temperature results are strong, but the seasonal baseline marginally outperforms Random Forest on the supplied MAE, RMSE and R².
    • Spatial charts show sampled grid points and are not continuous interpolated maps.
    • Forecast horizon, input data availability, uncertainty, independent validation and operational monitoring require further assessment.
    • Joblib model files are included in the package but must be loaded and run in a compatible Python environment.
